Drivetrain Physics Simulator

Sep 2025 – present

Purdue Electric Racing — drivetrain simulation & controls

Physics models in MATLAB that simulate EV drivetrain dynamics, so the team can predict performance metrics up front instead of discovering them on track. Every question the simulator answers is a physical testing cycle nobody has to run.

Steering and throttle response algorithms are derived from historical testing data rather than idealized curves. That mattered most in the two regimes where an idealized model is least honest — corner entry and hard acceleration — and that is where simulation fidelity improved.

MATLAB · vehicle dynamics · controls

Autonomous Drone Search & Rescue System

Feb 2024 – Aug 2024

Independent project

An end-to-end autonomous drone platform for locating missing persons. A custom CNN handles object detection, CUDA-accelerated so inference runs in real time on the aircraft — a search drone that has to ask a ground station what it's looking at is a search drone with a radio link as its single point of failure.

I built the full software stack in Python and Java: flight path planning, onboard sensor fusion, and the glue between them. The hardware enclosure was modeled in CAD. Field tests gave reliable detection performance, which is the part that only shows up once ML, embedded software, and physical hardware have to agree with each other in the same airframe.

Python · Java · CUDA · CNNs · CAD
