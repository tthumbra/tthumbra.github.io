Drivetrain Physics Simulator

Sep 2025 – present

Purdue Electric Racing — drivetrain simulation & controls

Physics models in MATLAB that simulate EV drivetrain dynamics, so the team can predict performance metrics up front instead of discovering them on track. Every question the simulator answers is a physical testing cycle nobody has to run.

Steering and throttle response algorithms are derived from historical testing data rather than idealized curves. That mattered most in the two regimes where an idealized model is least honest — corner entry and hard acceleration — and that is where simulation fidelity improved.

MATLAB · vehicle dynamics · controls

Autonomous Drone Search & Rescue System

Feb 2024 – Aug 2024

Independent project

An end-to-end autonomous drone platform for locating missing persons. A CNN classifies thermal frames for person-presence on the aircraft itself — a search drone that has to ask a ground station what it's looking at is a search drone with a radio link as its single point of failure.

The 150 gram payload budget drove the model choice. The first working version hit 94% accuracy in a 1.41 GB file no Raspberry Pi could run; four trials later a 224×224 MobileNetV2 reached 97.41% in 4.5 MB. I built the rest of the stack in Python and Java (flight path planning, onboard sensor fusion) and modeled the enclosure in CAD.

Python · Java · TensorFlow · MobileNetV2 · CAD
