Autonomous Drone Search & Rescue System

Feb 2024 – Aug 2024

Independent project

An end-to-end autonomous drone platform for locating missing persons. A CNN classifies thermal frames for person-presence on the aircraft itself, so the radio link to a ground station is not a single point of failure.

The 150 gram payload budget drove the model choice. The first working version hit 94% accuracy in a 1.41 GB file no Raspberry Pi could run; four trials later a 224×224 MobileNetV2 reached 97.41% in 4.5 MB. I built the rest of the stack in Python and Java (flight path planning, onboard sensor fusion) and modeled the enclosure in CAD.

Python · Java · TensorFlow · MobileNetV2 · CAD
